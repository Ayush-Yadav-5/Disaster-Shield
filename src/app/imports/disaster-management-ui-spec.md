Design a modern, clean, and visually appealing UI for an AI-powered Disaster Management web platform. The interface should look professional, minimal, and structured like a real-world emergency operations dashboard while still being visually engaging.

STYLE & FEEL:
Use a clean and elegant design with lots of white space. Follow a modern dashboard aesthetic similar to Stripe or Vercel dashboards. Avoid clutter and excessive colors. The UI should feel serious, calm, and trustworthy while still looking polished and premium.

COLOR SYSTEM:
Primary color: Blue (#2563EB)
Alert colors: Red (#EF4444), Yellow (#F59E0B), Green (#10B981)
Background: Soft gray (#F8FAFC)
Use subtle gradients and soft shadows for depth.

TYPOGRAPHY:
Use modern fonts like Inter or Poppins. Clear hierarchy with bold headings and clean body text.

LAYOUT REQUIREMENTS:

1. LANDING PAGE:
   • Clean navbar with logo, Features, About, Login
   • Hero section with large heading:
   “Real-Time AI Disaster Management Platform”
   • Subheading explaining reporting, alerts, coordination
   • CTA buttons: “View Dashboard” and “Report Disaster”
   • 3 feature cards with icons (Live Alerts, Smart Prediction, Coordination)

2. MAIN DASHBOARD:
   • Left sidebar navigation (Dashboard, Report Disaster, Map View, Alerts, Profile)
   • Topbar with search, notifications, profile avatar
   • Stats cards row (Active Disasters, High-Risk Alerts, Volunteers Active, Reports Today)
   • Large central interactive map with markers and heatmap toggle
   • Right-side live activity feed panel

3. REPORT DISASTER PAGE:
   • Centered card layout
   • Multi-step form design
   • Fields: disaster type dropdown, map location picker, severity slider, description box, image upload
   • Bold red “Submit Report” CTA button

4. MAP VIEW PAGE:
   • Full-screen map layout
   • Filter panel (left)
   • Incident detail panel (right)
   • Clean legend design

5. ADMIN PANEL:
   • Clean table layout
   • Approve/reject report controls
   • Broadcast alert modal design

DESIGN DETAILS:
Use card-based layouts, rounded corners, subtle shadows, consistent spacing system (8px grid), soft hover effects, and smooth transitions.

The design must look polished, clean, realistic, and portfolio-worthy.
